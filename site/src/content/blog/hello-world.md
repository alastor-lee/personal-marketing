Welcome to the new site. This blog is built with [Astro](https://astro.build) and
authored in plain Markdown — each post is a single file in `src/content/blog/`.

## Why a rebuild

The old site was hand-written HTML with a lot of copy-pasted markup. Moving to Astro
means the nav, footer, and page chrome live in **one** place, and content like this
post is just prose.

- More posts
